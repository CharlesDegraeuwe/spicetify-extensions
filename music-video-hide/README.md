# music-video-hide

A Spicetify extension that hides the music video player and related UI elements in the Now Playing view, keeping the classic album art experience.

## What it hides

- The music video player
- The music video badge/icon on tracks
- The Now Playing section that gets replaced by the video player
- The track info badges

## Installation

1. Build and install the extension:
   ```bash
   npm run build && spicetify apply
   ```

2. Restart Spotify.

## Development

Build and apply changes:
```bash
npm run build && spicetify apply
```

Then press `Ctrl+Shift+R` in Spotify to reload.
